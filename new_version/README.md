# 新版 RizomUV 2027 exe 汉化补丁链

本目录保存针对**新版 RizomUV 2027 exe**（英文原版 MD5 `abbc69339a373f08cbc3507111d97fbf`）的界面汉化补丁与安装脚本，与仓库根目录针对旧版 exe 的工具相互独立。

## 重要：严格串行的 MD5 链

这批补丁是**逐批叠加**的，后一批的安装脚本会校验前一批安装后的 MD5。必须按下表顺序安装，不能跳批、不能混用旧版工具：

| 顺序 | 内容 | 脚本 | 安装后 MD5 |
|---|---|---|---|
| 0 | 英文原版（使用者自备正版） | — | `abbc69339a373f08cbc3507111d97fbf` |
| 1 | 主汉化迁移（621 词） | `build_new_version.py` + `一键安装新版汉化.bat` | `cf53e1496873dffba10983d180a0cdcf` |
| 2 | 顶部工具栏 7 个分组标题 | `patch_toolbar_titles.py` + `一键安装工具栏补译.bat` | `8018ad29b03772d8b51f8c676220e334` |
| 3 | Transform 面板 8 个界面标签 | `patch_transform_panel.py` + `一键安装面板补译.bat` | `651a25b166ab27091f6dcc0695756529` |
| 4 | 菜单 6 个界面标签 | `patch_menu_safe6.py` + `一键安装菜单6词.bat` | `ef85533b797c7fc841e9c26bd676efae` |

每批的 `.bat` 都会：校验当前 exe 的 MD5、关闭中的进程检查、自动备份、替换、复核，任一环节不符即停止并写入 `install_result_*.txt`。

## 安全原则

- 只改 UI 字符串区 `0x6d00000–0x6e20000`，区外零改动，文件大小不变。
- UTF-8 中文写入原有零填充槽，绝不越界、绝不加长文件。
- 危险词与命令名/枚举值一律不翻：`Protect`、`Strategy`、`Tags`、`Transform`、`Shape`、`Move`、`Rotate`、`Off/Planar/Curved` 等。
- 每批都从已装版本派生，只动当批的少数几个独立槽位。

## 说明

- `verified_dict.json` 是从旧版"最终完整版"与英文原版差分提取的 723 条已验证安全词条，主迁移据此写入 621 条。
- 脚本中的安装路径与源文件路径为本机构建环境的实际路径，作为可复现记录保留；换机使用时需按实际环境调整。
- 这些脚本不修改任何程序逻辑、配置键或内部命令名，仅替换界面显示的文字。
