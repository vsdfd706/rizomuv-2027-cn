# RizomUV 2027 简体中文补丁

只把 RizomUV 的**界面文字**变成简体中文，**不动任何功能**——加载、展开、排布、旋转、脚本桥接与英文原版完全一致。本仓库**不包含也不分发 RizomUV 程序本体**，只提供补丁工具；需要你自己持有正版授权的英文原版。

## 先选对你的版本

仓库按版本分成两套独立工具，**不能混用**。请先看你装的是哪个版本，再进对应目录（exe 内部可查到准确版本号）。

| 你的 RizomUV 版本 | 用哪套工具 | 一键入口（双击即用，无需 Python） | 英文原版 MD5 |
|---|---|---|---|
| **新版本 2027.0.648 Win** | [`v648/`](v648/README.md) | `v648\dist\RizomUV汉化工具_648.exe` | `abbc69339a373f08cbc3507111d97fbf` |
| **老版本 2027.0.598 Win** | [`v598/`](v598/README.md) | `v598\dist\RizomUV汉化工具.exe` | `2ddf8d6da2000ae3eac66d7eea59a311` |

> **怎么知道自己是哪个版本**：打开 RizomUV，看关于/标题，或在安装目录对 `rizomuv.exe` 右键属性看版本信息。装错工具会在校验时明确提示“版本不匹配”，不会改动文件。

## 三步搞定（以新版本为例）

1. **完全关闭 RizomUV**。
2. 双击 `v648\dist\RizomUV汉化工具_648.exe`（老版本则用 `v598\dist\RizomUV汉化工具.exe`）。
3. 按窗口提示操作，看到“全部完成”即可。工具会自动备份原版、创建桌面中文快捷方式。

想改回英文：用同目录下的 `一键还原.bat`（或工具里的还原功能），原版已自动备份，随时可恢复。

## 安全设计（两套通用）

- 只改 exe 的 **UI 字符串区**，SDK/代码/数据区一律不动，文件大小不变。
- UTF-8 中文写入原有零填充槽，绝不越界。
- 黑名单、指针密集区、键名保护、零填充预算检查全部保留。
- 危险词与命令名/枚举值一律不翻（`Protect`、`Strategy`、`Tags`、`Transform`、`Shape`、`Move`、`Rotate`、`Off/Planar/Curved` 等）——误译这些曾导致模型空白、旋转失效，现已全部规避。
- 每套工具都先校验英文原版 MD5，不符立即中文提示并停止，不会改错文件。
